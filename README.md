# VIP Player Intelligence

Веб-приложение, которое анализирует переписки VIP-менеджеров с игроками. Оно оценивает качество общения, находит нарушения и риски и показывает приоритет обращения со ссылками на конкретные сообщения.

Для тимлидов и руководителя VIP-отдела iGaming-компании.

## Установка

Нужен компьютер с Windows, macOS или Linux. Все команды ниже вводятся в терминале (в Windows: PowerShell, в macOS и Linux: Terminal).

### Шаг 1. Установите Python

1. Проверьте, есть ли Python: введите `python --version`. Нужна версия 3.10 или новее.
2. Если Python не найден или версия старше, скачайте его с https://www.python.org/downloads/ и установите. В Windows в первом окне установщика обязательно поставьте галочку **Add python.exe to PATH**.
3. Закройте и снова откройте терминал, повторите `python --version`.

### Шаг 2. Скачайте проект

Вариант А, через Git:

```
git clone https://github.com/X40S/VIP_Project.git
cd VIP_Project
```

Вариант Б, без Git: на странице репозитория нажмите **Code**, затем **Download ZIP**, распакуйте архив и откройте терминал в папке `VIP_Project`.

### Шаг 3. Установите зависимости

В папке проекта выполните:

```
pip install -r requirements.txt
```

Команда скачает все нужные библиотеки. Это делается один раз.

### Шаг 4. Запустите приложение

```
python -m uvicorn app.main:app --port 8000
```

Когда в терминале появится строка `Uvicorn running on http://127.0.0.1:8000`, откройте в браузере http://localhost:8000.

Терминал не закрывайте: пока он открыт, приложение работает. Чтобы остановить его, нажмите `Ctrl+C`.

## Настройка

Ключ AI нужен только для режима «AI-анализ». Без ключа можно пользоваться режимом «Импорт анализа» (см. ниже).

### Как получить бесплатный ключ Google Gemini

Gemini используется по умолчанию: у него есть бесплатный тариф, банковская карта не нужна. Бесплатный тариф имеет лимиты на число запросов в минуту и в день, для демо-набора из `sample/` их обычно хватает.

1. Откройте https://aistudio.google.com/apikey и войдите в свой Google-аккаунт.
2. Нажмите **Create API key** и выберите проект (или создайте новый).
3. Скопируйте ключ. Он выглядит как длинная строка, начинающаяся с `AIza`.
4. Никому не показывайте ключ и не публикуйте его в репозитории.

### Как ввести ключ в приложении

1. Откройте раздел **Настройки**.
2. Выберите провайдера **Google Gemini**.
3. Вставьте ключ в поле API-ключа. Модель уже выбрана по умолчанию, менять её не нужно.
4. Нажмите проверку подключения. Если появилась отметка об успехе, ключ работает.

Другие провайдеры (Anthropic, OpenAI) настраиваются так же, но они платные.

## Использование

### Основной способ: AI-анализ

Нужен API-ключ (см. раздел «Настройка»).

1. Откройте раздел **Анализ чатов**, режим **AI-анализ**.
2. Выберите файлы `dialogs.json` и `players.csv` и нажмите «Загрузить данные». Тестовые файлы лежат в папке `sample/`.
3. Нажмите «Анализировать все». Перед запуском показываются модель, объём и приблизительная стоимость, запуск только после подтверждения.
4. Если часть диалогов уже проанализирована, прежние результаты сохраняются. Галочка «Проанализировать заново» пересчитывает их.

### Если нет AI-ключа: готовый анализ

В `sample/analysis_results.json` лежит анализ тестовых диалогов, уже выполненный с помощью AI. Его можно открыть без ключа и без запросов к AI:

1. Раздел **Анализ чатов**, режим **Импорт анализа**.
2. Выберите `sample/analysis_results.json` и нажмите «Импортировать».
3. Чтобы видеть сами переписки и данные игроков, загрузите `sample/dialogs.json` и `sample/players.csv` в режиме «AI-анализ» (кнопка «Загрузить данные»). Анализ при этом не запускается.

Свой готовый анализ можно подготовить и в Claude Code: инструкция `docs/CLAUDE_CODE_ANALYSIS_GUIDE.md`, схема `schema/analysis_results.schema.json`.

### Работа с результатами

- Список диалогов: поиск и группировка (по приоритету, менеджеру, каналу, игроку, статусу анализа).
- Карточка диалога: оценка менеджера, эмоциональная динамика, нарушения, рекомендации, данные игрока. Ссылки на сообщения ведут к нужному месту в переписке.
- Результаты каждого анализа сохраняются в папку `results/` и могут быть открыты снова через «Импорт анализа».

### Правила анализа

Раздел **Правила анализа** задаёт, по каким критериям AI оценивает переписки: например, как должен вести себя менеджер и что считается нарушением. Правила разбиты по категориям. Здесь можно изменить существующее правило, добавить свое или отключить ненужное.

Каждое сохранение создаёт новую версию (`v1`, `v2` и так далее), к любой из них можно вернуться. Новые правила применяются к следующему анализу без перезапуска. Уже готовые результаты при изменении правил не пересчитываются, а получают отметку «Правила изменены».

Оценки эмоций и вовлечённости приблизительные, это интерпретация модели, а не измерение состояния. При сигналах самоисключения и риска вреда от игры приложение не допускает рекомендаций по депозитным стимулам.
